== Description ==

Custom WordPress-Theme für Auto Emotion.

== Installation ==

1. Theme-Ordner nach wp-content/themes/ hochladen.
2. Im WordPress-Backend unter Design > Themes aktivieren.
3. Menüs unter Design > Menüs den Positionen "Hauptmenü" und "Footer-Menü" zuweisen.
