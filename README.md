# Auto Emotion

Projekt-Repository für die Zusammenarbeit mit der **Auto Emotion GmbH & Co. KG** (Ansprechpartner: Christopher Placzek) – Aufbau einer Recruiting-Landingpage sowie begleitende Marketing-/SEO-Arbeiten für Seat, Nissan und Cupra.

## Struktur

```
.
├── assets/
│   └── images/        Bildmaterial (Fahrzeug-Renderings etc.)
├── docs/
│   ├── briefing/       Fragenkataloge, Kontakte, Projektgrundlagen
│   └── reports/        SEO-/KI-Optimierungs-Reports
└── site/               Quellcode der Landingpage (Aufbau folgt nach Design-
                        auswahl unter styles.refero.design und Briefing-
                        Antworten von Auto Emotion)
```
